| D25 | 2026-11-14 | P7 agent loop rules. (1) Text at the start of a round is held until 160 chars or turn end: if a tool call follows, it becomes a **reasoning** step instead of answer text, so preambles never leak into the answer; short answers therefore arrive in one `answer.delta`. (2) `[S#]` citations are filtered while streaming (split citations held back), so the client never sees an invented id. (3) Media from `open_sources` goes in a user message **after** all tool results of the round (providers reject media in tool messages); text pieces are inlined; media per call is capped by `maxMediaPartsPerRequest` and the rest fall back to thumbnail + stored text. (4) Attachments are named `A1..A3` to the model; only the current turn's attachments are searchable. (5) The last of 6 rounds is sent with no tools so the model must answer. (6) The assistant message, steps and cited sources are saved in one transaction, also on disconnect (`_(Stopped.)_`) and error. | Keeps the activity log honest and the answer clean without a contract change. | Claude |
